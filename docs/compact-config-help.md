# 紧凑配置详情

控制台配置页采用渐进披露：配置行只保留标题、当前状态和输入控件，完整说明按需查看。

## 交互

- 普通配置字段及“闸门模式”标题右侧都有圆形 `?` 按钮。
- 点击或键盘激活后打开单项详情弹层，显示内部字段名、完整解释、示例1和示例2。
- `Escape`、关闭按钮或点击遮罩均可关闭；关闭后焦点返回原来的 `?` 按钮。
- 手机端两个示例改为单列；桌面端并排展示。
- 顶部“参数手册”继续提供全局搜索，并与单项弹层复用同一份说明和双示例数据。

## 代码结构

`FIELD_HELP` 保存字段解释和第一个示例，`FIELD_EXAMPLE_2` 保存第二个示例，`helpExamples()` 统一输出两个示例。`buildField()` 只渲染紧凑标题和 `?` 入口，不再把长说明常驻在配置行下方。

闸门模式不是普通输入字段，因此使用独立的 `MODE_CONFIG_HELP`，但弹层行为与其它配置一致。

## 验证

- 普通字段的解释及第二示例均有完整映射，页面不存在旧 `.field-notes` 常驻说明。
- 完整离线回归包含普通保存、分段同步、回复交接与运行记录；可选宿主/配套源码通过环境变量提供。
- 配置详情均显示两个示例。
- 1280像素和390像素页面无横向溢出，暗色模式正常。
- 参数手册可通过第二示例内容搜索到对应字段。
